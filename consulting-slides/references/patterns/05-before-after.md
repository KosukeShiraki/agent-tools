# 05. 前提の転換｜Before → After（縦に3〜4セット）

**使う場面**：技術や手段ではなく「考え方・前提」を変える必要があることを示す。
**要点**：左＝従来（淡色・通常ウェイト）、右＝あるべき（白地・ネイビー枠・太字）。左右は必ず同じ論点について書く。4セットを超えない。最も重要なセットを最後に置き、図の下に注記で理由を書く。

```html
<div class="ba">
  <div class="hd2"></div><div class="hd2">これまでの前提</div><div class="hd2"></div><div class="hd2">これからの前提</div>
  <div class="no">01</div>
  <div class="l">{従来の認識}</div>
  <div style="display:flex;align-items:center;justify-content:center"><div class="ar"></div></div>
  <div class="r">{新しい認識}</div>
  <!-- 02, 03, 04 も同形 -->
</div>
<p class="nt" style="margin-top:16px">※ {最重要セットの補足}</p>
```
